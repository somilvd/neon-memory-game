# neon-memory-game
Neon Memory es un juego de memoria estilo arcade hecho con HTML, CSS y JavaScript puro. Incluye niveles de dificultad, sistema de vidas, temporizador, efectos visuales y partículas interactivas sin usar bases de datos ni frameworks.
# Neon Memory

Un juego de memoria estilo arcade desarrollado con **HTML, CSS y JavaScript puro**, sin frameworks ni base de datos.

El objetivo es encontrar todos los pares de cartas en el menor tiempo posible, gestionando tus vidas y aprovechando los bonus de tiempo.

---

## Demo del juego

-> Abre `index.html` en tu navegador y empieza a jugar.

---

## Características

- Sistema de dificultad:
  - Fácil (10 vidas)
  - Medio (12 vidas)
  - Difícil (15 vidas)

- Sistema de vidas dinámico:
  - Pierdes vidas al fallar
  - Ganas vidas al acertar

- Temporizador con bonus:
  - +5 segundos por cada acierto

- Diseño estilo arcade neon:
  - Efectos glow
  - UI moderna

- Efectos visuales:
  - Partículas verdes al acertar
  - Animaciones en los mensajes de recompensa

- Responsive:
  - Adaptado a móvil, tablet y escritorio

- Sin dependencias:
  - No usa frameworks
  - No usa base de datos

---

## ecnologías usadas

- HTML5
- CSS3 (Flexbox + Grid + Animaciones)
- JavaScript (Vanilla)
